# Feature request: tags for notes

From: a notes user

I keep a few hundred notes and I can't find anything. I'd like tags:

- put tags on a note, and take them off again;
- list only the notes that have a given tag;
- rename a tag everywhere at once (I misspelled "recipies" on forty notes);
- see the tags when I export my notes.

Tags shouldn't care about case: `Work` and `work` are the same tag.
