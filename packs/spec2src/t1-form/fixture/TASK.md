Build the `form` app described by CONTRACT.md, SKILL.md, features.yaml and examples/ in this directory. Deliver source and an executable POSIX-sh launcher `./form` at the workspace root. `./form` is run on Linux x86_64 with Go 1.27, Python 3.12, Node 18, sh, curl and jq, with no network and no bashy. It may compile on first use, and dependencies must be standard library only or vendored here. Your work is judged by its behaviour: the contract's commands and the page it serves. The judge's tool is on your PATH: `conform run CONTRACT.md --path . --fresh-home` runs every assertion in CONTRACT.md against your `./form` and prints PASS or FAIL for each. Use it while you build.

dag.md in this directory is the app's lifecycle and is part of the spec. Do not change it. Make each of its steps work when its code block is run with `sh` from this directory on the same Linux machine: `build` (you supply `build.sh`), `test`, `install`, `run`, `serve` and `stop` (you supply the `serve` and `stop` commands of `./form`; CONTRACT.md has the service rules). `./form` must still work when `build` has not been run.
