# Manager profile — per-area ability (θ)

Each area is fitted on its own (score(m,b) = sigmoid(a_b·θ_m − d_b + h_harness + s_source), regularised quasi-binomial maximum likelihood (dispersion φ from Pearson residuals), Levenberg–Marquardt on the exact Hessian from a fixed start); θ is standardised within the area over the models it covers. Role = weight-averaged θ; weakest = lowest weighted area; hands-on = θ over the hands-on areas. Line = lowest anchor role − 1.645·se. Hands-on is relative: a model *can manage* a worker when its hands-on θ − 1.645·se ≥ the worker's hands-on θ (nobody manages uphill). A model with no rows in an area sits 0.5 below that area's lowest model and is flagged *must measure* (ᶠ). Inherited rows come from the same line's predecessor.
